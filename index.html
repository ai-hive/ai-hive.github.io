ai-hive

A personal, single-user assistant system.

ai-hive is a private project that helps its owner keep track of tasks, reminders and incoming email. It runs on the owner's own home server and is not offered to the public; there is no sign-up.

What it does

  • Reads new messages in the owner's Gmail inbox (read-only) and decides which ones need attention.
  • Reads the owner's Google Calendar (read-only) to include events in daily summaries.
  • Sends the owner short summaries and reminders through a private chat.

It never sends, deletes or modifies email or calendar events.
